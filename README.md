# 笑蛙冲刺 · 跑酷原型

横屏侧面跑酷原型。玩家控制 GIF 奶蛙左右移动、跳跃、二段跳和翻滚，收集三只大笑奶蛙后合成一次捧腹大笑冲击波。

## 本地运行

```bash
npm install
npm run dev
```

### 无边框桌面小窗

```bash
npm run desktop
```

桌面小窗固定为 720 × 405，只显示游戏内容，没有网址栏、关闭或最小化按钮。拖动窗口最顶部的透明区域可移动位置；使用 `⌘Q`（Windows 为 `Ctrl+Q`）退出。

## 操作

- `A` / `D`：左右移动（可到达约 81% 的横向位置）
- `空格` / `↑`：跳跃、二段跳
- `S` / `↓`：翻滚
- `E`：笑值满三格后释放冲击波

## 当前范围

- 自动奔跑与递增速度
- 跳跃、二段跳、翻滚
- 四类障碍
- 三只大笑奶蛙合成与冲击波
- 大笑后重置全部障碍，获得 3.2 秒保护，并延迟 5 秒重新生成障碍
- 气鼓鼓暴走道具
- 头顶跟随式大笑奶蛙技能槽：收集几个显示几个，集满三只后提示释放
- 打拳奶蛙暴走形态、金色脉冲光与自动上移的实时剩余时间条
- `P` / `Esc` 或界面按钮暂停、继续及返回主页
- `H` 或界面按钮一键清屏并自动暂停，恢复画面后保持暂停
- 无边框桌面小窗，固定 16:9 且不显示浏览器或系统窗口边框
- 距离、分数、本地最高分与立即重开
- 本机 Top 5 排行榜（自动记录分数、距离和时间，保存在当前浏览器）
