# 笑蛙冲刺 · 跑酷原型

横屏侧面跑酷原型。玩家控制 GIF 奶蛙左右移动、跳跃、二段跳和翻滚，收集三个大笑形态后合成一次捧腹大笑冲击波。

## 本地运行

```bash
npm install
npm run dev
```

## 操作

- `A` / `D`：左右移动
- `空格` / `↑`：跳跃、二段跳
- `S` / `↓`：翻滚
- `E`：笑值满三格后释放冲击波

## 当前范围

- 自动奔跑与递增速度
- 跳跃、二段跳、翻滚
- 四类障碍
- 三笑脸合成与冲击波
- 大笑后 1.6 秒保护与屏幕障碍清场
- 气鼓鼓暴走道具
- 距离、分数、本地最高分与立即重开

跑步与捧腹大笑角色动画来自公开网络素材，详情见 [ASSET_SOURCES.md](./ASSET_SOURCES.md)。其他图形与程序化音效为原型自制。
