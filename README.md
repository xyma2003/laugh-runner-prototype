# 笑蛙冲刺 · 跑酷原型

横屏侧面跑酷小游戏。奶蛙会自动向前奔跑，玩家需要左右调整站位、跳跃或翻滚躲避障碍，同时收集大笑奶蛙与暴走道具，尽可能跑得更远、拿到更高分。

🎮 **[在线试玩](https://xyma2003.github.io/laugh-runner-prototype/)**（手机请横屏）

## 游戏规则

### 基础目标

- 奶蛙会自动奔跑，速度随游玩时间逐渐提高。
- 撞上障碍且没有保护效果时，本局立即结束。
- 基础分数由奔跑距离产生，每前进 `1 m` 获得 `10` 分；收集道具和摧毁障碍还会获得额外分数。
- 一局结束后可以立即重开，也可以查看本机 Top 5 排行榜。

### 四类障碍

- **木箱、路钉、裂缝**：主要通过跳跃或二段跳越过。
- **飞行器**：可以通过翻滚降低碰撞高度，从下方穿过。
- 奶蛙可以在屏幕约 81% 的横向范围内左右调整位置，为下一次跳跃或收集道具提前站位。
- 障碍会从 16 种安全组合中随机生成，并随奔跑时间逐步解锁更难的组合；最近三种组合不会重复。

### 大笑合成

- 每收集一只大笑奶蛙，头顶增加一格大笑槽，并获得 `75` 分。
- 教学阶段的道具会在两个安全高度间变化，之后会加入第三个更高的位置，出现间隔和入场位置也会随机变化。
- 集齐三只后可以释放捧腹大笑冲击波。
- 冲击波会清除当前场上的全部障碍，每清除一个障碍额外获得 `180` 分。
- 释放后获得 `3.2` 秒碰撞保护，并将下一批障碍至少延迟 `5` 秒生成。

### 暴走状态

- 收集打拳奶蛙后进入 `3.1` 秒暴走，并立即获得 `150` 分。
- 暴走期间撞上木箱、路钉或飞行器会将其撞飞，并额外获得 `120` 分。
- **暴走无法撞开裂缝**，仍需跳过去；碰到裂缝会结束游戏。
- 奶蛙头顶会显示暴走形态和实时倒计时条，时间清空后暴走失效。

### 排行榜

- 自动记录本机最高的五次成绩，包括分数、距离和记录时间。
- 排行榜保存在当前浏览器的本地存储中，因此手机、电脑和不同浏览器会分别记录。

## 操作方式

### 电脑键盘

- `A` / `D`：左右移动
- `空格` / `↑`：跳跃；空中再次按下可二段跳
- `S` / `↓`：翻滚
- `E`：大笑槽满三格后释放冲击波
- `P` / `Esc`：暂停或继续
- `H`：一键清屏并自动暂停

### 手机触屏

- 使用左下角按钮按住向左或向右移动。
- 使用右下角按钮跳跃、翻滚或释放大笑。
- 支持多点触控：可以一根手指持续移动，另一根手指同时跳跃、翻滚或释放技能。

## 小窗摸鱼模式

仓库内提供独立的无边框桌面小窗，不显示浏览器网址栏、关闭按钮或最小化按钮，只保留游戏画面：

```bash
npm install
npm run desktop
```

- 窗口固定为 `720 × 405`、16:9，适合放在桌面角落游玩。
- 拖动窗口顶部区域可以移动位置。
- 按 `H` 一键清屏时会自动暂停：游戏画面隐藏，窗口变为透明，只在右上角保留时间。
- 点击右上角时间或再次按 `H` 恢复画面；恢复后仍保持暂停，避免游戏偷偷继续。
- macOS 使用 `⌘Q`，Windows 使用 `Ctrl+Q` 退出；也可以使用 `⌘W` / `Ctrl+W` 关闭小窗。

运行 `npm run dev` 后，也可以在本地主界面点击“无边框小窗”直接打开。重复点击只会唤醒已有窗口；这个入口仅在 `localhost` 或 `127.0.0.1` 显示。

## 普通本地运行

```bash
npm install
npm run dev
```

终端显示本地地址后，在浏览器中打开即可。电脑可直接使用键盘；如需让同一局域网内的手机访问，可以运行 `npm run dev -- --host 0.0.0.0`，再打开终端显示的局域网地址。

## 当前已实现

- 自动奔跑、递增速度、左右站位、跳跃、二段跳与翻滚
- 木箱、路钉、飞行器和裂缝四类障碍
- 16 种逐步解锁且防连续重复的随机障碍组合
- 三只大笑奶蛙合成、清场冲击波与短时碰撞保护
- 打拳奶蛙暴走形态、实时倒计时和撞飞障碍
- 键盘与手机多点触控
- 暂停、返回主页、一键清屏和立即重开
- 距离、分数、本地最高分与本机 Top 5 排行榜
- 浏览器版与无边框桌面小窗
